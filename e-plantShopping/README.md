# e-plantShopping: Paradise Nursery

A React and Redux Toolkit-based e-commerce application for Paradise Nursery, where users can browse houseplants categorized by type, add them to a dynamic shopping cart, and manage cart items seamlessly.

## Features
- **Landing Page**: Visually inviting welcome page with company description and direct entry.
- **Product Listing Page**: Houseplants organized into categories with real-time stock button disabling upon selection.
- **Header & Navigation**: Dynamic cart item badge counter reflecting total quantity across pages.
- **Shopping Cart**: Item quantity adjustments (+/-), total cost computation, item removal, and checkout notifications.

## Tech Stack
- **React** (Vite)
- **Redux Toolkit** (State management)
- **CSS3** (Custom responsive styling)
